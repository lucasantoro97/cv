# Luca Santoro — Academic CV and Portfolio

Personal website of Luca Santoro, Fixed-term Assistant Professor at Politecnico di Torino and Co-founder & CEO of Therness.

The site presents research, publications, talks, projects, and professional experience in non-destructive testing, active thermography, welding process monitoring, computer vision, and industrial AI.

## Live website

[lucasantoro97.github.io/cv](https://lucasantoro97.github.io/cv/)

## Development

This site uses [Hugo Blox Builder](https://hugoblox.com/) and deploys to GitHub Pages through [the Pages workflow](.github/workflows/publish.yaml).

```bash
hugo --minify --baseURL "https://lucasantoro97.github.io/cv/"
npx pagefind --site public
```

Hugo version: `0.136.5` extended.
